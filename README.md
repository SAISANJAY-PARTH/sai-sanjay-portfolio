# Sai Sanjay — Portfolio Website

A responsive portfolio for analytics, financial technology, AI-assisted workflows, business intelligence projects, coded/no-code website demonstrations, and spreadsheet-based finance tools.

## Run locally

1. Extract the ZIP.
2. Open `sai_portfolio/index.html` in a modern browser, or serve the folder with any static web server.
3. Keep the `assets/` and `downloads/` folders alongside `index.html`.

## Project structure

- `index.html` — page content and project sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation, project filters, and expandable project details
- `assets/` — project screenshot previews
- `downloads/Sai_Sanjay_Resume.pdf` — resume download
- `downloads/Sai_Sanjay_Cover_Letter.pdf` — cover letter download
- `downloads/*.xlsx` — source workbook assets retained in the ZIP for your own management; they are not linked for direct public download from the website
